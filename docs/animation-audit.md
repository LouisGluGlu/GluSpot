# 动画审计

宽窄切换卡，是因为固定时长曲线和拖动过程中每帧都在拆掉内容再重画。这次改用同一套弹簧，并让拖动的每一帧都继续画已经有的内容。

## 弹簧

弹簧没有固定时长。质量、刚度和阻尼比决定路径。阻尼比是主要旋钮。

- 宽窄切换和展开背景：阻尼比 1，刚度 220，质量 1。停住，不来回晃。
- 边缘回弹和轻轻放开：阻尼比 0.8。会过一下再回来。
- 列表惯性：阻尼比 1，刚度 180。

参数在 `local/spring_motion.py` 的 `WIDE_NARROW_SPRING`、`EDGE_SPRING`、`SCROLL_SPRING`。换数值只改这里。

所有新弹簧共用一个刷新率定时器。没有弹簧在动时，定时器停掉。`GLUSPOT_FRAME_LOG=1` 会打印每帧间隔和丢帧。

松手时的速度会送进弹簧。中途改目标时，位置和速度都接着走，不跳回起点。

## 这次录屏里的五件事

1. 拖动时歌词变成灰条，窗口有一块是透明的。原因：宽度一变就把歌词拍成一张图，180 毫秒后把这张图丢掉，改画灰色占位条。占位条只盖住旧的一块，新拉出来的区域没有背景，透出桌面。现在已经有歌词时，冻结期间一直留着这张图，并把它画进当前这一帧的歌词区域。没有拍到图时，就直接画正在显示的歌词，不留空。还在查歌词的歌才继续用会动的占位条。

2. 封面、歌名、按钮一帧一个位置，不是连续移动。原因：一过临界宽度，布局立刻切到目标那一档，时间动画再慢慢追。手指还按着时，姿势现在跟窗口宽度走。松手后，弹簧从当前姿势补完剩下的路。

3. 宽布局歌名在左边缘被硬切，例如只剩 `E EXCUSES. (v2) [fe`。原因：歌名矩形跑到窗口左边外面，画的时候直接被窗口裁掉，没有渐隐。现在把跑出去的部分拉回左边缘内 12 像素，并在这一侧做淡出。

4. 右下角的歌名小牌和波形按钮压在歌词上。原因：宽窄切换时歌词列会铺满窗口，歌名和私人 DJ 波形仍画在同一块区域，遮罩又按“已经到窄布局”瞬间切换。现在切换过程中，歌词绘制会让开歌名区域和波形按钮。

5. 非当前行的模糊歌词有一圈暗边。原因：模糊结果是直通透明通道，画上去时被当成预乘颜色，边缘的黑色透出来。现在转成预乘图再画，边缘保持歌词自己的颜色。

岛展开和收回时，起点图和终点图现在按同一条临界阻尼弹簧交叉。不再在 38% 处把原来的背景直接拿掉。

歌词滚轮、播放列表和资料库网格：手指或触控板的速度会留给弹簧。已经在边缘再推，才会橡皮筋；一次滚到头不会被拉开。鼠标的一格滚轮仍停在原来的那一行，避免把现有点击和滚轮测试带跑。

## 帧时间

同一套离屏测量：宽窗口切到窄窗口后，尺寸不动，连续画 24 帧。

| | 改之前 | 改之后 |
| --- | ---: | ---: |
| 每帧绘制中位数 | 4.05 毫秒 | 1.97 毫秒 |
| 每帧绘制最大值 | 68.0 毫秒 | 69.6 毫秒 |
| 绘制期间 CPU | 204 毫秒 | 173 毫秒 |
| 玻璃绘制调用中位数 | 5 | 0 |
| 动画结束后每帧中位数 | 1.00 毫秒 | 0.85 毫秒 |
| 动画结束后这段 CPU | 12.6 毫秒 | 11.4 毫秒 |

最大值仍是第一帧要准备玻璃。稳定下来之后更轻。动画结束、定时器停掉之后，CPU 没有比原来更高。

## 怎么看对比

在仓库根目录：

```bat
_demos\spring_transition\弹簧宽窄对比.bat
```

或：

```bat
python _demos\spring_transition\demo.py
```

左边是原来的固定时长。右边是弹簧。下面可以调阻尼比和刚度，并有一条带初速和边缘回弹的列表，以及展开时背景跟着走的对比。
