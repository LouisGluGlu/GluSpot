# GluSpot 窄窗演示

三个独立运行的演示使用同一组假歌曲、歌词和布局，不连接网络、不读取用户数据，也不会播放声音。双击对应的批处理启动；路径使用 `E:\gpt-island\.venv\Scripts\python.exe`，需要该环境安装项目依赖。

- **方案 A · 封面飞入**：宽窄切换时，封面与歌名平滑移动、缩放，歌词区域连续重排；开关和底部图标采用清透玻璃。
- **方案 B · 淡入切换**：同样的布局与玻璃控件，切换时旧布局淡出、新布局淡入。
- **方案 C · 无底图标**：同方案 A 的飞入动画，开关和底部图标使用纯图标，仅开启项有半透明底。

鼠标拖动窗口边缘调整宽度；列表内滚轮滚动，点击开关及底部歌词/列表图标可切换状态。

键位：`L` 歌词、`P` 列表、`Tab` 切换模式、`N` 窄窗、`W` 宽窗、`←/→` 每次改变 60 像素、`1–4` 切封面颜色、`Space` 暂停/继续歌词、`H` 显示/隐藏提示、`Esc` 退出。标题显示最近一秒刷新次数。

命令行可使用 `--grab DIR` 保存宽歌词、窄歌词、窄列表及五张过渡帧后退出；`--seconds N` 自动退出；`--bench N` 输出最后 N 次 paint 的中位数和 p95 毫秒。性能数字是 Qt 绘制耗时，不包含系统合成器和屏幕显示。
