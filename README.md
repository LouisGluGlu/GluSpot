# GluSpot

Windows 桌面音乐悬浮岛，让歌词、专辑和播放状态融入桌面。

[发行记录](https://github.com/LouisGluGlu/GluSpot/releases) · [6.415 安装程序与便携版说明](docs/windows-release-ui-login-6.415.md) · [最新源码改进与验收清单](docs/ui-login-followup-2026-10-20.md)

- **音乐与歌词**：网易云、QQ 音乐库及 Windows SMTC，支持逐词读亮、翻译和可靠前奏／间奏提示。
- **桌面显示**：Free、Top 和沉浸栏，搭配 Liquid Glass 控件与专辑取色背景。
- **播放布局**：封面、封面内歌词、封面外歌词和播放列表，随窗口宽度切换。
- **音频输出**：本机与兼容 AirPlay 设备，可组合多设备同步播放。

适用于 **Windows 10 1809+／Windows 11 x64**。安装版支持原目录覆盖升级并保留配置；便携版需完整解压后运行 `GluSpot.exe`，配置默认保存在程序旁的 `GluSpot` 文件夹。当前 **6.415 为未签名测试版**，设备兼容与验证边界见本版报告。

源码入口为 `local/main.py`。开发环境运行 `setup-env.bat` 后使用 `launch.bat`；完整测试为 `python -m unittest discover tests -v`，Windows 构建使用 `build-exe.bat` 和 `packaging/windows/build-installer.ps1`。

## Placement Modes

- `Free` (`free`): floating music island. The compact surface is a maximum-radius rounded rectangle; its expanded surface preserves readable cover, lyric and control margins.
- `Top` (`top`): island pinned to the physical screen's top edge, with a flat upper edge and rounded lower corners.

MyDockFinder and Tasker are mutually exclusive:

- MyDockFinder running with an enabled real MyFinder bar: allowed modes are Finder Bar and Free. A newly enabled bar automatically selects Finder Bar; routine polling preserves a user's later Free selection.
- MyDockFinder running without an enabled MyFinder bar: Top and Free are available. A running Dock process alone does not create a Finder Bar.
- MyDockFinder not running: available families are Free, Top and 沉浸栏 (Tasker Bar).
- Dock presence blocks Windows taskbar auto-hide recognition and automatic taskbar attachment, including when Free is selected, because the Dock can hide the Windows taskbar itself.
- Dragging onto the Windows taskbar without Dock selects Tasker; dragging to the physical screen top selects Top. With Dock and Finder, only a hit on the actual Finder bar attaches Finder; other positions are Free. With Dock but no Finder, a screen-top release selects Top.

Enabled: immersive islands follow their owner's live slide and hide, releasing input when hidden; Dock without Finder hides its Top island during external fullscreen. Disabled: a hidden owner temporarily falls back to visible, topmost Top and returns to its immersive bar when that owner reappears. This temporary Top does not become a manually selectable mode in Dock+Finder environments. Fullscreen exit does not cancel an outstanding hidden-owner fallback.
