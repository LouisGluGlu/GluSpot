`api/lyric_timeline.py` 现按原文的词／CJK 字符统计整首真实逐字覆盖率，忽略附属译文、罗马音；混合行内仍保留独立真实词锚点的贡献。一个长词拆成多个音节，不会被重复计成多个词。

## 第二阶段：安全升级整首来源

已有歌词先显示。仅当整首真实词覆盖率达到 **95%** 才停止寻找更精细的来源；部分逐字数据仍进入现有有限回退序列。每一个跨源候选（包括首个 QQ 逐字结果）都需通过原文兼容检查。候选需提高覆盖率，且不能通过删除大段歌词取得更高比例；失败、未命中和不兼容结果保留当前可用歌词。

本样本此前没有选入 AMLL，原因是官方 48 行与 AMLL 43 行的原文完全相同行只有 29 对，`29/48=60.4%`，未达到原有 80% 行匹配门槛。制作信息、不同换行、口语拼写及独立括号人声影响该比值；单纯降低门槛会允许遗漏正文或换入其他录音。

新规则保留原有严格行兼容路径，并仅为**双方完整、相同、已验证的不可变歌曲身份**增加整首原文验证：

- 身份包含平台、歌曲 ID、标题、歌手、专辑和时长。相同平台不同 ID、不同录音元数据不能通过此路径。
- 原文 token 按顺序双向匹配至少 95%；真实词数量、正文总量均有保留门槛。
- 至少有 3 对完整相同行锚点；短于 3 行时需要全部。锚点需覆盖双方至少一半 token 和一半人声时间范围，时间差不超过 0.75 秒。
- 相匹配 token 若同时是双方行首，也需通过 0.75 秒检查；重复副歌不能独自授权替换整段不同主歌。
- 择源只排除明确制作字段，保护已验证的歌手标签、括号和声及冒号正文；不把展示层的未知署名块扩展用于提高匹配率。

本样本去除明确制作字段后的官方原文为 336 token，AMLL 为 331 token，有序匹配 326：覆盖率分别为 **97.02% / 98.49%**。29 对完整行锚点覆盖 token **72.02% / 73.11%**，最大行首偏差 **0.434 秒**，因此整首升级通过。缺少已验证身份时仍拒绝。

跨源附属文本继续走原有严格兼容检查；本样本官方 → AMLL 的附属文本合并结果仍为 **拒绝**。不会将官方译文直接套在换行或时钟不兼容的 TTML 上。切换译文／罗马音时，从保留的原始来源重新解析。

明确版本校验同时补上 Radio Edit、Extended 和具体 remixer／现场地点／重制年份，防止同一大类的不同录音因标题相似而获信任。大小写、标点和通用 `Version` 后缀可规范化；`feat.` 括号本身不被当作版本。相同 ID 的 AMLL 响应也不能绕过这些检查。

身份信任仅在当前进程有效，不写入持久歌词缓存。同标题／歌手的缓存现在按明确专辑或显著时长冲突区分录音上下文，连同后台请求、失败冷却、择源与可信 ID 一并隔离；正常时长抖动保留容错。生成文件只保存普通请求元数据，不保存信任声明；旧文件缺少所请求的录音字段时保留文件并重新取词。手工歌词继续优先。重载的生成缓存必须先与新取得、已验证的同一官方原始内容核对，才可用于上述整首升级。手工本地歌词保留优先权；旧请求仍受歌曲身份、catalog、播放 epoch、歌词代次和清缓存代次保护。

## 第三阶段：统一展示时序

`local/lyric_unit_timing.py` 的不可变显示计划供窗口／全屏、封面内外歌词和岛态复用。源单位保持原样；仅临时显示单位可插值，标明 `estimated` 及 `timing_origin`，不写回 provider、原始歌词或持久缓存。

| 显示计划 | 处理方式 |
| --- | --- |
| `word` | 保留源词／音节锚点及已有结束时间；缺失结束的显示补全仍标估算 |
| `segment` | 保留真实多词片段边界，只在片段内部按词分配显示时间；同起点片段先合并，避免入场即跳到末词 |
| `estimated` | 具有安全行区间的 LRC 按该行播放位置渐进读亮，沿用现有下一行提前预览策略 |
| `line` | 无安全区间、合成行或无可靠后继的普通尾行，保持整行回退，不编造长时逐字区间 |

对唱共享已核验的组边界；只有估算声部可借同时间伙伴的真实正文起点，交错入场保持各自起点。歌手前缀可从估算的人声时长中排除，但保留原文映射。真实词／片段锚点不因对唱布局而移动。换行后的各视觉行通过同一源字符前沿绘制，避免只修改总进度而底层绘制仍使用旧计划。实际渲染还查出金标高光资源冷启动时，旧回退将进度乘二并丢掉已经映射的视觉行前沿，导致整行提前亮起；现直接使用同一估算计划及映射前沿，保持原有高光风格。新增四布局回归强制覆盖这一冷路径。

完整回归还查出源词缺少结束时间时，显示补全误用了提前预览后的边界，可能使尾词提前一秒完成。现在仅这类缺失结束取下一原始边界；已有明确结束时间、重叠长音不移动，普通 LRC 的预览策略保持原样。括号和声按可见正文的末五分之一推进；对唱译文使用各自声部的计划，避免将另一声部的进度套入。新增回归同时核对源单位、原始括号边界、暂停及跳转时钟。

暂停、快进、回退从当前实际播放位置重算；切歌清理旧亮色状态。岛态不同样式及 Ember 偏移使用同一计划，移除半秒内整行扫亮的独立路径。长音高光仍使用源真实单位及现有固定 0.8 秒门槛，不把插值升级成真实长音。

前奏／间奏仍由展示层独立计算：前奏保留 5 秒规则，间奏要求严格超过 3 秒且有可靠源结束证据；插值不参与判断，不生成估算尾奏。译文、过滤结果或源歌词变化会重建显示计划及提示段。
