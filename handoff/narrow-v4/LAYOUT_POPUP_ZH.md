# 窄窗布局与弹窗中文说明（t120）

本轮按当前任务要求交付中文说明；统一弹窗组件仍待实现与验收。本文件区分现有布局与后续弹窗目标，不把设计稿当作已经运行的功能。

## 当前布局

- 顶部集中放置返回音乐库、喜欢／加入歌单、输出设备、播放顺序、布局切换、译文和窗口模式；私人 DJ 按现有可用条件显示。
- 底部只保留上一首、播放／暂停、下一首。继续使用现有播放控件样式。
- 只有允许返回音乐库时才显示返回入口。该入口不可用时，喜欢／加入歌单使用左侧空间，窗口模式仍在右侧；左上角点击不能误触放大到 960 像素。
- 窄窗与宽窗共用四种内容：专辑封面、封面内歌词、封面外歌词、播放列表。改变宽度只适配几何布局，不替换所选内容模式。

以上以 `ca63388`、`791ccef`、`77a7f32` 和当前共享实现为依据。旧 t118 草案中的“底部五按钮一排、喜欢／加入歌单位于其上方”已由 t138 顶部布局取代，不作为本轮改动目标。

## 统一弹窗的后续目标

输出设备菜单与加入歌单菜单应复用同一套外壳规范：圆角、玻璃材质、封面取色、字体、间距、开合动效、锚点定位和关闭规则。各菜单保留自己的数据、权限与操作回调。

原设计参数供后续实现核对，尚未通过本轮代码或 PC 验收：

| 项目 | 设计目标 |
| --- | --- |
| 外壳与项目圆角 | 外壳 14，项目悬停 10 |
| 留白与行高 | 上下 12、左右 8；项目行高 36 |
| 定位 | 与按钮间隔 8，视口边距至少 12；优先向上展开，空间不足时翻转并水平约束 |
| 材质 | 背景模糊 20，封面取色透明度 72%；缺少封面时使用纯色回退 |
| 字体 | 标签 14／行高 20，选中项加粗；图标 18 |
| 打开 | 160 毫秒，三次缓出；纵向位移 6→0，透明度 0→1，缩放 0.98→1 |
| 关闭 | 120 毫秒，二次缓入；纵向位移 0→4，透明度 1→0 |
| 关闭触发 | 点击外部、Escape／返回、选择项目、列表滚动超过 8、窗口尺寸或方向改变；一次操作只关闭一次 |

数值沿用旧设计稿的逻辑单位，后续须结合现有 Qt 界面与 DPI 规则核对，不直接当作物理像素。

## 实现与验收边界

当前设备面板由 `local/audio_output_panel.py` 中的 `AudioOutputPanel` 提供，入口为 `MusicSurfaceWindow._open_audio_output_panel`；歌单面板由 `local/music_song_collection.py` 中的 `SongPlaylistPanel` 提供，沿用现有收藏入口。后续应先核对这两个现有组件及其调用处，再提取可复用外壳；本轮不新增弹窗接口，也不改播放、收藏、排序或设置行为。

弹窗开合不得重建歌词图层或重新模糊当前歌词。背景模糊应在打开时准备并缓存，避免叠加到实时歌词上。窗口变化时应结束当前弹窗，避免锚点跳动。
