# GluSpot 6.415 Windows 发行记录

日期：2026-10-20。本地构建、完整回归、双包校验与本地备份已完成。

[GitHub 发行入口](https://github.com/LouisGluGlu/GluSpot/releases/tag/v6.415)。远端发布及附件可用状态以该入口为准；本地已校验文件如下。

本版包含[九项界面、封面及登录改进](ui-login-followup-2026-10-20.md)，以及 6.414 的 MyDockFinder 底部拖动消失修复。使用 Windows 10 1809+／Windows 11 x64，未签名测试版。

## 本版改进

- 中性 Liquid Glass 控件、宽窄模式切换次序与可持续显示的 DJ 状态外框。
- 登录、音乐库及播放页共用可调整窗口尺寸；鼠标焦点边框与退出确认修复。
- 高清封面相同像素不再无限等待；歌曲、歌单搜索独立返回并优先加载缩略图。
- 先恢复受保护账号快照，后台严格核验；旧请求精确取消、有限重试、QQ 设备上下文复用及超时统一。

## 使用

安装版在原安装目录覆盖升级，保留配置。便携 ZIP 完整解压后运行 GluSpot.exe，保留旁边的 _internal；配置默认在程序旁 GluSpot 子目录。新目录首次启用选择程序内播放与系统抓取。

旧版本分发包保留。新安装程序、便携 ZIP 和两份校验文件同时保存于：

- 当前工作区 `release/`
- 本机主工作区 `E:\gpt-island\release`
