# GluSpot 6.50

> 歌在岛上停靠，词随鼓点涨落。

6.50 是 6.417 之后的一次大版本整理：海平面背景、窄版窗口、音乐库、岛态吸附与网易云精确抓取都重新打磨了一遍。Windows 文件版本为 **6.500.0.0**，因此能从 6.417 正常覆盖升级。

## 海平面背景

- 从封面取色重新设计：保留封面自己的色相，按 OKLab 距离与色彩和谐度挑选搭配，不再只有红蓝、黑白、黄蓝几种拼法。
- 闪光以鼓点为第一优先，人声门槛更高，光斑更小、不再晃眼。
- 岛态变色缩短为 1.5 秒，慢—快—慢缓入缓出。
- 白底读字时，未读字改为深灰／灰白，与背景拉开层次。
- Apple Music 歌曲也能使用海平面（借用网易云的分析结果并缓存）。

## 窗口与全屏

- 全屏、窗口与岛之间的形变改为在固定画布内动画，不再逐帧缩放原生窗口，过渡明显更顺。
- 窄版：更大的平滑圆角；隐藏时封面与歌名缩小而不消失，封面对齐左上边距；新增进度条；私人播报在缩小版式中保留。
- 换行歌词读到第二行不再弹跳；翻译行不再越界。
- 二级菜单（设备控制、添加到歌单）改为与按钮一致的 Liquid Glass 材质，行改为扁平状态，文字随主题取色。
- 控件玻璃边缘修正，按钮背景颜色跟随背后画面。

## 音乐库

- 歌单详情页：可插播、下一首播放、加入歌单。
- 搜索支持模糊匹配与搜索历史，结果缓存，搜索更快；搜索结果可插播。
- 侧栏点击无响应的问题已修复。

## 音乐岛

- Finder 模式：透明背景保留可点击区域，岛始终置顶，不会再点穿到 Finder 栏。
- 吸附：岛体至少 50% 与吸附位重合才吸附；满足条件时按住 1 秒则停在当前位置；吸附动画不再抽搐。
- Top 模式可横向移动；任务栏模式会识别任务栏图标，自动收缩到空隙里，不挡图标。
- 自动隐藏的任务栏／Finder 栏：全屏且没有任何栏时，自动切换为超矮 Top。
- 修复岛在窗口打开时带着旧歌曲弹出的问题；岛态翻译行不再溢出。
- 私人播报的表情样式：去掉了问号、省略号等装饰，只保留表情与动作，眼睛不再抽搐。

## 网易云精确抓取

- 按播放器自己的歌曲 ID 获取官方歌词与原图封面，不再因标题搜索拿到别的版本或乱码歌词。
- 修复进度互相跳转：网易云回调给出的“时长”可能落在播放头之后，曾导致 GluSpot 收不到任何进度、无法跳转；现在两边拖动进度都会互相跟随。
- 系统媒体会话没有时长时，使用歌曲自身时长。

## HomePod 与输出

- HomePod 投放组件随安装包与便携包一起提供；设置 → 播放 → 音频输出可查看组件状态。

## 设置

- 翻译：所选次行内容缺失时自动改用另一项（普通话歌曲选“音译”不再空白）；粤语歌曲可选“显示粤拼”或“跟随次行内容”；繁体转换不再把“你”变成“妳”。
- 歌词页重新分组为“读字 / 次行 / 文字”；播报样式移到外观；网易云精确进度说明不再被遮挡；高级页显示版本号。

## 已知限制

- 未签名测试版；首次运行可能需要在 SmartScreen 中选择“仍要运行”。
- 物理多屏、长时间多设备同步播放与 QQ／酷狗的完整体验仍需更多实测。
- 个别系统完整测试仍有既有失败项（与本版改动无关），详见维护者文档。
