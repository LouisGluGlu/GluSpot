## 登录改动及边界

- [x] 保存账号先恢复受保护的本地资料和首屏音乐库快照，后台核验；缓存状态 `cached` 的 `logged_in` 始终为 false，未核验数据不赋予在线操作权限。
- [x] 快照仍在现有 DPAPI 凭据封装内，按平台和账号绑定，最多保存每类首屏 100 项、展示有效期 30 天；没有引入明文账号缓存或新凭据目录。
- [x] 同进程已验证账号复用；并发账号核验合并；临时失败保留缓存和受保护记录，明确失效或身份变化才清理对应账号。
- [x] 队列、认证锁、启动、管道写入和 HTTP 共用剩余总预算；登录任务默认总预算 18 秒，实际网络使用剩余值，不靠延长超时遮盖阻塞。
- [x] 丢弃尚未执行的旧任务；精确取消所属平台正在运行的认证请求，关闭对应拥有的子进程以中断不支持独立取消的请求，不关闭共享音乐通道或其他平台。
- [x] 旧 attempt 不得取消新代次；取消信号与新代次注册在短锁内排序。独立的代次取消事件随请求传递到认证入口，覆盖 QQ 本地记录读取后的空档，不反向获取 service 锁。该锁不等待网络或子进程回收。
- [x] 登录池固定 2 个 worker、队列上限 24；账号头像使用独立的固定 1 个 worker，不再占满两个认证工作线程。其他既有业务池保持原有边界。
- [x] 临时轮询失败保留有效二维码，最多 3 次退避重试，1 秒正常轮询且不重叠；扫码确认后只重试账号核验，不重新扫码。
- [x] 真正的过期、取消、可恢复网络错误、运行时丢失扫码会话、登录失效和复核失败分别显示。Node 硬超时导致内存 QR 会话丢失时，要求刷新，不假装旧二维码仍可恢复。
- [x] 固定 QQ SDK 3.1.4 的设备上下文与扫码会话分离；受保护记录可恢复设备上下文，不能复活已退出 token 或覆盖已保存账号会话。HTTP 使用剩余预算和 AbortSignal。
- [x] QQ SDK 带失败阶段的 `800` 不再全部误报过期：真实过期仍 expired，用户取消为 cancelled，已终止的交换／网络失败为 error，并要求刷新。只传固定错误类别、阶段和中文提示，不转发 SDK 原始错误文本。
- [x] 仅预热当前／首选平台；仅预热而未使用的认证通道 60 秒回收。每个平台最多一个活动认证子进程，每条通道最多两个待回收进程，达到回收上限时拒绝继续创建。回收在后台进行。
- [x] 不完整账号响应（包括 `user_id=None`、布尔值、对象等）不得授权，也不误删有效缓存；扫码确认后的此类响应只重试复核。
- [x] 阶段日志只允许平台、操作、阶段、耗时、代次和错误类别，不包含账号标识、二维码、Cookie、Token 或签名 URL。

参考 Folia 固定提交 `62c35156b01e165201dc999e0961f2e0e6dff68c` 的实际账号恢复实现：

- [accountRead.ts](https://github.com/chthollyphile/folia-major/blob/62c35156b01e165201dc999e0961f2e0e6dff68c/src/services/onlineMusic/account/accountRead.ts)：缓存先展示、按平台合并核验、代次隔离。
- [src/services/onlineMusic/providerAccountCache.ts](https://github.com/chthollyphile/folia-major/blob/62c35156b01e165201dc999e0961f2e0e6dff68c/src/services/onlineMusic/providerAccountCache.ts)、[providerStorage.ts](https://github.com/chthollyphile/folia-major/blob/62c35156b01e165201dc999e0961f2e0e6dff68c/src/services/onlineMusic/providerStorage.ts) 及 [netease/neteaseProvider.ts](https://github.com/chthollyphile/folia-major/blob/62c35156b01e165201dc999e0961f2e0e6dff68c/src/services/onlineMusic/netease/neteaseProvider.ts)：临时错误与明确失效分别处理。
