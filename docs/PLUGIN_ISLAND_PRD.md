# 插件岛 PRD

状态：首轮实现中。已完成插件条下挂式展开面板、上下文操作、面板内提醒轨、时间/天气/日程管理控制；后续继续打磨视觉动效和更多诊断。

## 目标

把插件岛从“附属装饰条”升级成一个手机小组件风格的轻量操作面板。方向参考 iOS 小组件、实时活动、灵动岛和控制中心：第一眼能扫到关键信息，展开后能做一件有用的事，设置里能配置和诊断，但不做成复杂仪表盘。

## 对标结论

市面上的手机端小组件大致分三类：

- 系统原生状态面板：比如 iOS 实时活动和灵动岛，强项是常驻、克制、只展示当前最重要的信息，展开后再给更多操作。
- 成套小组件应用：比如 Widgetsmith、iScreen，强项是天气、倒计时、日历、待办、快捷启动等类别齐全，用户上手快；缺点是样式容易变杂。
- 深度编辑器：比如 Widgy，强项是自由编辑和数据源很多；缺点是学习成本高，不适合 gpt-island 现在直接照搬。

所以插件岛不建议先做“自由小组件编辑器”。更合适的是：先做少量高质量、强默认值的插件，让每个插件都能立即有用，再逐步加入配置能力。

## 产品原则

- 一眼可读：收缩态每个插件只显示一个主要事实。
- 可操作：展开态至少提供一个自然操作，而不是只放更多文字。
- 风格统一：不同插件共用同一套图标、标题、颜色、状态层级。
- 安静现代：纯色、浅色、轻阴影、清晰分隔，避免渐变和过度装饰。
- 本地优先：能用本地或系统数据的先做；联网插件必须有加载、失败、过期状态。

## 三个界面层级

### 收缩插件条

用途：常驻快速扫一眼。

每个插件格子包含：

- 一个图标或符号。
- 一个一行摘要。
- 一个纯色强调色。
- 可选的小状态点，比如加载、过期、警告。

不放长描述，不放多行设置，不用渐变。

### 展开插件岛

用途：hover 或单次点击收缩插件条后，保持原 48px 插件条不变，并在其下方新增一个独立圆角面板，用来聚焦一个插件，同时保留其他插件的轻量入口。

展开行为：

- 插件条本体不被拉高，仍保持三插件横向信息密度。
- 下方面板使用弹簧过渡从插件条下方展开；自动向上展开模式下则镜像到插件条上方。
- 点击插件条只展开/聚焦，不直接打开插件管理窗口；管理窗口作为面板动作或设置入口。

聚焦插件显示：

- 图标块。
- 主信息。
- 副信息。
- 一个上下文操作。
- 活跃提醒会融入面板底部的横向提醒轨，保留环形进度语言。

非聚焦插件保持小尺寸，只显示图标或图标加短值。

### 插件管理界面

用途：配置、诊断、真实控制。

统一结构：

- 顶部：插件名、状态、上次更新时间。
- 快捷操作：1-3 个命令。
- 设置项：iOS 风格左右开关、选择器、输入框。
- 诊断：数据来源、刷新结果、权限状态、错误信息。

## 推荐先做顺序

1. 时间 / 计时器

本地能力最稳定，适合先打通“收缩态-展开态-管理界面”的完整流程。

2. 日程

先支持本地 JSON，后续再支持 ICS。这样实现风险更低，也方便调试。

3. 消息

项目里已经有消息检测基础，可以把应用开关、权限状态、最近检测结果放进管理界面。

4. 天气

天气使用免 Key 公共数据源，优先尝试系统定位，失败后回退到手动城市。后续重点继续优化权限提示、天气动画和过期状态。

## 视觉方向

- 插件岛整体使用接近 iOS 的浅色纯色壳。
- 插件强调色使用纯色，不使用渐变。
- 图标放在圆角方块里，类似 iOS app 图标或控制中心模块。
- 文本以深色为主，副文本用灰色。
- 收缩态高度保持 48 px，除非未来某个插件进入特殊实时状态。
- 音乐岛可以继续用专辑色和氛围渐变；插件岛不要跟着音乐岛走渐变风格。

## 数据结构方向

当前可以继续兼容 `api/plugin_provider.py` 的数据，但 V2 插件模型建议逐步变成：

- `id`：插件唯一标识。
- `label`：显示名称。
- `icon`：图标。
- `accent_color`：纯色强调色。
- `primary_value`：主信息。
- `secondary_value`：副信息。
- `status`：正常、加载、过期、失败等状态。
- `last_updated_at`：最后更新时间。
- `actions`：可执行操作。
- `settings_schema`：设置项描述。
- `diagnostics`：诊断信息。

## 暂不做

- 不做插件市场。
- 不做任意拖拽式小组件编辑器。
- 不做插件脚本运行时。
- 不恢复旧 Pill UI。
- 不恢复旧 live-media 源码树。

## 已落地方向

- 插件管理界面先保留独立轻量窗口，同时设置页也合并主要配置项。
- 天气先走免 Key 公共天气源，支持定位优先与手动城市回退。
- 日程支持本地 JSON / ICS 路径，保留课表读取录入和课表提醒功能路线。
- 首个完整插件流以时间 / 计时器为基准，天气和日程跟进同样的展开态与管理结构。
