# GluSpot 窄窗 v2 实验

本目录是独立的假数据窗口，不连接播放服务、不访问用户数据、不发声。三个入口共享同一窗口代码：A 将播放控制放进底部悬浮玻璃岛；B 将播放控制并入头部；C 将播放控制留在左下角，沿用宽窗四角关系。

运行 `demo_island.py`、`demo_header.py` 或 `demo_corners.py`，Windows 可用对应批处理。`--grab DIR` 保存宽窗、窄窗歌词、收起状态、列表和过渡帧；`--seconds N --bench N` 输出最后 N 次绘制以及过渡绘制的中位数与 p95。`check_layout.py` 检查窄窗交互控件的矩形（不包含内容区或控件按压变形）。

键位：L 歌词，P 列表，Tab 切换，N/W 窄/宽，左右方向键调宽，1–4 切换配色，空格暂停，H 提示，Esc 退出。列表滚轮滚动，点击歌曲切换；播放、喜欢、DJ 可点击。

复用：`GlassControlRenderer`、`ControlFeedback`、`artwork_surface_palette`、`background_role_color`、音频输出图标、内容布局图标、窗口模式图标、音乐来源图标（返回、喜欢、加入歌单）、私人 DJ 图标。浮岛从实时内容画面采样，其他控件从背景采样；过渡时缩放缓存玻璃。

复刻：渐变背景、歌词布局/逐字填亮和缓存模糊、进度光轨、头部收起与窗口过渡、假封面。transport 形状参考 `MusicSurfaceWindow._paint_transport_icon`，但三角形为简化版本；翻译和播放模式图标为简化文字，未调用原始路径。内容重排尚未交叉淡化，歌词换行上移也未完全复刻宽窗运动。

当前为未完成的视觉实验，不满足发布验收：玻璃重建造成的绘制 p95 超过 16.7 ms；歌词未实现多行换行；浮岛和胶囊未随宽窄过渡完整飞入；控件按压时放大和邻居移动尚未覆盖所有图标和组合胶囊；检查脚本只检查静态控件命中矩形。仅在 Linux offscreen 环境验证，尚未进行 Windows 真机验证。
