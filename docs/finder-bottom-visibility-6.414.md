# MyDockFinder 底部拖动消失修复 · 6.414

2026-10-20。修复 MyDockFinder 与真实 Finder 栏启用时，岛拖到底部松手后永久消失的问题。安装程序与便携包按版本、日期保存在本地 `release`，保留此前版本。

## 原因与修复

拖动时展开方向保持锁定，避免岛在鼠标下跳动。旧代码把没有命中 Finder 栏的拖放也标记为“已处理”，因此跳过 Free 岛的正常释放定位。松手后布局重新计算为向上展开，岛在透明窗口内的局部位置改变，原生窗口位置却没有补偿，最终完全移出屏幕。

本机只读探测确认实际运行的是 `Dock_64.exe`，存在启用且可见的真实 `MyFinderApp` 栏。使用其真实边界与生产 Qt 绘制路径，修复前岛由 `y=1040` 移到 `y=1385.5`，不透明度仍为 1、输入穿透关闭；这不是托盘隐藏，也不是检测不到 Finder。

修复只调整两个既有路径：实际命中 Finder 栏才消耗拖放；其他位置继续使用现有 Free 定位。定位前记录实时弹簧的全局矩形，移动原生窗口后恢复，避免松手首帧短暂上跳。修复后首帧为 `y≈1039.95`，最终为 `y=1039.5`，岛完整保留在屏幕内。MyDockFinder 环境仍禁止 Windows 任务栏吸附；真实 Finder 命中与无 Dock 时的 Tasker 接入保持原规则。

未改变页面布局、控件、音频状态、账号、设置目录或外部 Dock 配置。
