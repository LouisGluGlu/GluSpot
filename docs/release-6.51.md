# GluSpot 6.51

> 换上耳机，歌就跟过去；颜色到了高潮，就一下子亮开。

6.51 是 6.50 之后的一次体验更新。Windows 文件版本为 **6.510.0.0**，可从 6.50、6.418 等版本原目录覆盖升级。

## 播放设备

- 单设备播放时，新连上的蓝牙耳机（或 Windows 设为默认的新设备，比如 USB 耳机）会自动接管播放，像手机一样；显示器喇叭醒来、局域网里新发现的 AirPlay 设备不会抢走播放。
- 窗口右上角的输出按钮恢复完整样式：单设备、多设备与同放时的设备图标，以及设备接入时滑出设备名的胶囊动画。

## 歌词与背景

- 纯色背景与海平面背景下，未读字带上背景的色调：深色背景上是同色系的浅色，浅色背景上是同色系的深色。
- 变色节奏重做：前 30% 的时间缓缓铺开，随后匀速快速推进，最后 5% 在高潮处轻轻收住；颜色落定的瞬间有一束柔和的光，反馈更明显。岛态变色使用同一条曲线。

## 已知限制

- 未签名测试版；首次运行可能需要在 SmartScreen 中选择“仍要运行”。
- 自动切换只针对程序内播放；系统抓取模式下由 Windows 自己决定默认设备。
