# GluSpot 6.416 Windows 发行记录

日期：2026-10-21。本版包含隔离性能分支上的累积源码，以及本轮滚轮和播放控件材质调整。适用 Windows 10 1809+／Windows 11 x64，未签名测试版。

## 改动

- 音乐库普通滚轮沿页面上下滚动；Shift＋滚轮左右滚动歌单横排，保留真实水平输入。
- 上一首、暂停／播放、下一首沿用原形状、点击范围与动画，使用右上角圆形按钮同款中性 Liquid Glass 材质。
- 包含共享歌词后台预计算、有界玻璃／背景像素任务、图层及字形复用、页面连续交接与隐藏资源清理。
- 包含返回音乐库错层修复：保护过渡目标位置，避免临时原生位置污染共享窗口几何；取消、反向、输入及屏幕变化释放保护。

本轮没有更改 AirPods 图标、收藏控件、页面布局、播放协议或歌词来源规则。

性能工作与实际数据见[6.416 阶段报告](animation-performance-6.416.md)、[返回错层跟进](animation-return-followup-2026-10-21.md)及[成对数值附录](animation-callback-followup-2026-10-21.md)。高 DPI 长帧、重场景稳定 60Hz 和高刷新率仍未达标；数据包含回归，不能概括为全面提速。离屏绘制、可见 Qt 回调与物理屏幕呈现分别记录。

## 使用

安装版在原安装目录覆盖升级并保留配置；同版／较低版覆盖需要交互确认。便携 ZIP 完整解压后运行 `GluSpot.exe`，保留同目录 `_internal`。配置默认位于程序旁的 `GluSpot` 子目录，新目录首次运行进入初始化。

真实账号、HomePod 听感、物理鼠标／屏幕呈现与长期多小时运行不由离线或惰性安装检查替代。
