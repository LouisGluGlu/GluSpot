# t110 选择演示

这里只有可运行的对照窗口，不改 GluSpot 的产品代码。

在仓库根目录运行：

```bat
E:\gpt-island\.venv\Scripts\python.exe -X utf8 _demos\choices_t110\run_all.py
```

也可以双击 `打开选择.bat`。数字键 `1` `2` `3` 切换方案，`Esc` 关闭当前窗口。

按钮沿用来源页的扁玻璃：半透明、1 像素亮边、没有高光。大块玻璃仍用现有的液态玻璃。背景用音乐库的 frosted。

| 窗口 | 方案 |
| --- | --- |
| 1 磁吸停靠 | 同一位置停超过 2 秒就停住，哪怕几乎重叠。只有 2 秒内松手且重叠过半才弹簧吸进去。拖动时岛只跟手。 |
| 2 译文图标 | 已选定 A 交叉滑过。图标大小还等补充，示例里的大小先不改。 |
| 3 窄窗隐藏 | 缩小后的封面用连续曲率圆角，圆角半径按封面尺寸等比缩小，不会收成圆。 |
| 4 添加到歌单 | 弹窗只负责加入。已经有这首歌时，A 变灰，B 打勾，都不能再点。排序、置顶、删除只在「个人歌单」。 |
| 5 宽版布局 | 已选定 A：保持布局 G，左列整组居中。B 和 C 只留在示例里对照，不再继续做。 |
| 6 来源页 | 已选定 A：右侧一块详情玻璃。 |
| 7 浅色界面 | 深色底和浅色底本身不同。滑块是「透明 ↔ 色调」：透出封面和亮边，或变成有颜色的实底。字始终清楚。 |
