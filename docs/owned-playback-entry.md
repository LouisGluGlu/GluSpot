# 首次播放选择、扫码登录与自主播放

2026-10-10，分支 `codex/owned-playback-sources`，源代码版本继续为 `6.412`。已有 EXE 没有重打包，安装动画仅生成预览 GIF。

## 用户已确认的界面与分流

首次启动显示双选项页面。默认选择“程序内播放”，可以同时选择“系统抓取”，至少保留一项。背景复用全屏歌词的 `AlbumFlowBackgroundRenderer`，每 5 秒切换完整配色；选中时边框发光，文字用现有歌词 reading renderer 在 0.78 秒内走过一次灰白到黑色的高光。点击小型“继续”后保存选择与完成标记。之后登录页的返回操作只收起二维码，不再回到首次选择页。

| 条件 | 首次确认后的去向 |
| --- | --- |
| 仅程序内播放 | 登录来源页 |
| 仅系统抓取 | 平滑收缩到屏幕顶部居中的现有 V2 岛 |
| 两项都选，有正在播放的系统媒体 | 顶部居中的岛 |
| 两项都选，没有正在播放的系统媒体 | 登录来源页 |

后续启动在没有正在播放的媒体、且没有受保护的登录记录时，主动显示登录页。已有记录的判断不依赖联网验证，离线不会把记录直接当作不存在。系统媒体探测等待真实 provider 状态，最多等 4 秒；记录读取在后台完成。播放中的媒体不等待账号记录读取。关闭窗口保留托盘程序，未确认选择不会写完成标记。

登录来源顺序是网易云、酷狗、QQ、汽水。四源选择为横向胶囊，选中后展开二维码面板，二维码使用粗来源主题色边框。后台提供 PNG 才显示二维码；错误、过期、切源、刷新和关闭均清理旧结果。选择来源时先在后台验证已有账号；有效账号显示头像、昵称和“进入”，头像有粗来源主题色圆边框。新扫码确认后保存账号并进入音乐库，不自动开始播放。后续启动如果只有程序内播放、系统无媒体且有记录，优先进入上次使用的已验证账号音乐库；联网验证失败保留登录页面的错误状态供重试，不删除记录。

## 登录后的音乐库

用户确认原图只是概念图，随后要求重新整理设计。音乐库现在采用分层深灰窗口、统一卡片、字体层级和间距。初次进入、上滚或悬停顶部区域时展开：64px 头像、当前平台及成组的平台切换/退出工具，每行三模式控件固定在右侧。下滚缩小账号区，封面和模式控件放大，控件移到标题下方；360 ms 动画可中途反转，同时保持真实列表滚动。返回、标题、关闭与搜索在两种状态始终可用，长标题省略，底部独立显示加载与错误。搜索当前平台的歌曲与歌单，350 ms 输入防抖，回车立即查询，两类结果按各自平台游标继续分页。清空搜索恢复账户歌单。网易展示每日推荐、私人漫游及账户歌单；推荐入口在后台读取真实歌曲封面，未取得图片时显示平台图标与类别文字。其他来源只展示其实际歌单，不虚构网易功能。

返回按钮与 Escape 先清空搜索，再返回来源选择页；平台切换同样回到来源选择页，不清除账号或停止已开始的播放。返回会作废尚未完成的开页请求，迟到结果不能打开歌词页。退出只删除当前来源受保护记录，并停止它的自主播放；完成后当前来源重新展开登录，其他平台继续显示已有账号卡。退出失败显示固定错误并允许重试。关闭库窗口作废待处理的目录、搜索、封面与播放转场；已开始的播放可由托盘/岛继续控制。

点击封面复用 `IslandStackVisual` / `MusicSurfaceWindow` 的截图几何转场，从所点击封面的真实全局矩形放大，默认沿用当前全屏/窗口偏好。三个控件显式选择全屏、窗口、岛。新曲必须取得授权流并由 Qt 实际确认 PlayingState 才交接；旧歌的停止/位置事件和仅完成流请求排队都不会提前开页。原有歌词加载和封面获取动画继续按真实 source state 工作；无封面、下载失败、无歌词与无播放权限均结束等待，失败保留列表并按安全错误代码显示原因，控件可以重试。

头像和列表封面按可见行加载，后台解码为 256px `QImage`，最多两个请求并发和 32 项待处理；窗口最多保留 48 张缩略图。歌曲原图按既有 provider 调色算法取色，使用独立后台队列；换曲、切源和关闭丢弃过时结果。原始 URL 获取受字节、尺寸和读取预算限制，不携带账号 Cookie。

设置的“媒体播放”页提供两个开关及“登录音乐来源”入口，最后一个开关不能关闭。独立键为 `v2_owned_playback_enabled`、`v2_system_capture_enabled`、`v2_playback_onboarding_completed`，没有复用原外部播放器进度适配键。旧配置缺少这些键时会显示一次新入口；损坏的双关闭状态恢复为程序内播放。

## 实现边界

- `api/online_music.py` 是同步账号、歌单、搜索、歌曲、流地址及歌词服务；`MusicLibraryController` 和入口控制器把调用放在 `MusicTasks` 的两个后台 worker，Qt 线程只接收快照。固定适配器契约、许可证与服务验证见 [在线运行时](online-music-runtime.md)。
- `native/online_music/bridge.cjs` 是独立编写的 stdio 适配器，没有监听网络 API 端口。固定使用网易 API 4.41.1、QQ API 3.1.4、酷狗 API 1.6.0 对应提交 `fe1838ae58ea69f84941ffa8758a34a9121bb2ea`。许可证和依赖锁保留在源码中，安装的全部依赖留在 ignored build 目录。
- 账户使用当前 Windows 用户的 DPAPI 保存到 `%LOCALAPPDATA%/GluSpot/accounts`，不会写入普通设置。公开快照不携带 Cookie、认证 session 或流地址凭据；Node 的原始日志丢弃，错误采用固定消息。扫码成功还需平台账号身份验证及加密保存成功，才进入 confirmed。
- `OwnedMusicPlayer` 使用 `QMediaPlayer` / `QAudioOutput` 自主解码和默认 Windows 输出。流就绪立即播放，歌词随后解析，真实 YRC 单位时间保留，坏 YRC 回退到 LRC。位置快照保留 Qt 的原始时间和采样时刻，不读取网易客户端歌词/进度窗口。
- 既有岛与歌词页会从后台线程调用播放命令和 Seek；自主播放器将这些请求排到 Qt 所属线程，后台最多等待 2 秒的实际结果。过期、关闭、已换曲的命令不执行，避免后台直接触碰 Qt 媒体对象或把未执行的定位宣称为成功。
- `PlaybackSourceProvider` 在 `api/providers.py` 内对接既有 V2 界面、命令及 Seek。自主歌曲有优先级；系统抓取关闭时不读取它的媒体快照或启用其输出路径。禁用程序内播放会停止解码并作废目录、流与歌词任务。
- 换歌、刷新、切源和关闭校验任务代次。过时分页在当前页返回后停止，排队的过时请求跳过网络访问。退出会立即作废登录并非阻塞关闭 Node，避免等待网络超时才退出。

NetEase 支持歌单及全量分页、每日推荐、私人漫游、新一批 FM 的 EOF 续播、可播放 URL、试听/无权限状态和 YRC/LRC；QQ、酷狗接入账号、歌单和流地址。平台原有会员/版权限制保留，无法获取授权地址时不会虚构可播放状态。QQ/酷狗逐字歌词尚未接入。

汽水没有在参考 Folia 中提供登录实现。Mineradio 的相应路径依赖混淆安全运行时和 Electron 宿主，当前 Qt 程序缺少可核验的接口与授权来源，因此保留明确不可用入口。

本次后续修复已接入自主播放器的直接 PCM 输出、单 Windows 设备切换及既有多设备时间线，同时补充歌曲页返回、前后三首缓存、播放模式和纯色封面处理。程序内音频不伪造外部捕获身份，也不改变系统默认设备。详见[当前行为、验证与限制](owned-playback-refinements.md)。在线长时播放及物理多设备听感仍未形成新的验证结论。

## 预览与可复现验证

```powershell
.\native\online_music\prepare-runtime.ps1
python .\tools\preview_install_animation.py
python .\tools\preview_playback_entry.py
python .\tools\preview_music_library.py
python .\tools\smoke_owned_playback.py
python .\tools\smoke_music_library.py
python -X utf8 -X faulthandler -m unittest discover tests -v
```

安装动画按参考六关键帧循环：空轮廓、三孔、分散 GLU、GLU spot、两孔、空轮廓。最新 v3 用几何遮块与不透明字形作等宽转换，没有文字 alpha crossfade：GLU 与 spot 各自整词变成一个圆角块，再扩大/合并；spot 从右向左进入并推动、横向压缩 GLU 后回弹。总时长 5000 ms，25 FPS 采样。六关键姿态保持，全部过渡端点及整词块连接连续性已检查。预览写到 ignored `logs/previews/installation`，v1/v2 保留作比较。它没有改变安装器。

界面预览写到 ignored `.runtime/playback-entry-preview` 和 `.runtime/music-library-preview`。二维码、账号和封面布局使用明确标记的 UI fixture，不表示真实账号已登录。

真实 Qt smoke 使用本机临时 HTTP 的 2 秒、44.1 kHz、双声道 WAV，音量只在本播放器设为零，未操作系统设备音量。14 项检查全部通过：真实 worker 调度、真实解码、进入 PlayingState、位置单调前进至 2000 ms、EndOfMedia 和 owned ended，无 Qt 错误。证据在 ignored `.runtime/owned-playback-smoke/result.json`。

音乐库联动 smoke 使用合成账户和本机音频，经过真实 `MusicTasks`、`OwnedMusicPlayer`、provider 边界与既有 `MusicSurfaceWindow`。49 项联动检查和 8 项实际 `LocalIslandApp` 构造/启动/关闭检查通过，合计 57 项：包括两种搜索的独立分页、封面全局矩形与截图起点、默认全屏/窗口交接、六行真实解析歌词、Qt 时钟、暂停/Seek、EOF，以及无封面终态释放加载反馈。结果与五张原生截图在 ignored `.runtime/music-library-smoke`。它未访问真实账号或外网，也没有系统抓取或全局音量变更；不证明授权播放、远程封面、AirPlay 或持续性能。

三平台真实匿名二维码创建与 waiting 轮询通过，未扫描、未登录、未播放账号歌曲。随后已有网易云账户的只读验证取得每日推荐、FM、歌单和授权流；两类首曲实际 Qt 静音解码、时钟与歌词解析均通过，加密登录文件前后不变。短测不证明扬声器听感、所有歌曲权限或长时同步。初次播放修复未修改 helper；后续直接 PCM 修复已重建 helper 并通过 12 组原生测试，见[最新验证](owned-playback-refinements.md)。两次均未生成新 EXE。

初版入口交付验证：`python -X faulthandler -m unittest discover tests -v` 的 3599 项测试全部通过（108.991 秒，无跳过）；真实 Qt 音乐库联动的 57 项检查再次通过。回归覆盖退出期间的搜索/点击、迟到账号和封面、失败重试、真实自主播放器同步停止信号、后台命令主线程转发、换曲/关闭与超时边界。Python 编译、Node 两份脚本语法和 Git 差异检查通过；46 个待提交路径经过生成文件/凭据检查。QQ 原始 MIT 许可证的一处尾空格逐字保留。后续修复有各自验收记录；当前全量数量以 README 为准，汽水、物理多设备听感、EXE 与性能限制继续保留。
