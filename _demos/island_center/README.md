# 岛歌词居中与磁贴

可运行的设计示例，不改 GluSpot 产品代码，不连接播放器，不启动网易云。

在仓库根目录双击 `岛居中与磁贴.bat`，或运行：

```bat
E:\gpt-island\.venv\Scripts\python.exe -X utf8 _demos\island_center\demo.py
```

`1` `2` `3` 换方案，`Tab` 在歌词和磁贴之间切换，方向键微调，`Esc` 退出。歌词页拖岛的右缘改宽度，拖封面改专辑位置。封面在产品里贴左，这里拖动只是模拟专辑位置变化。磁贴页点边角；方案 A 可以沿边拖。

按钮是扁平半透明玻璃：白填充约 56/74，1 像素亮边，没有高光。琥珀竖线和金色边距条只是示意。

离屏截图：

```bat
python -X utf8 _demos\island_center\grab.py
```

图在 `shots/`。示例把歌词岛画成产品的 48px 高胶囊（封面 32，内边距 8，字号 16）。磁贴用 1920×1080 的逻辑像素。
