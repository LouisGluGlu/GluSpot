# 播报动画示例

样式二圆脸的循环动画。只在这个目录里跑，不接进正式播放页，不改按钮、玻璃和播放模式，也不启动网易云。

动画文件是 Lottie。Qt 6 自带的 VectorImage 会用它自己的 Lottie 插件来播，不另装库。不播报时动画暂停，进出用的计时器也会停。

## 怎么打开

Windows 双击本目录的 `播报动画.bat`，或在仓库根目录：

```bat
_demos\broadcast_motion\播报动画.bat
```

按键：`1` 涟漪加张望（正式样式二用的这一条），`2` 只有涟漪，`3` 只有张望。空格开始或停止。`B` 切换深色和浅色。`←` `→` 换封面。`Esc` 退出。窗口下面的按钮做同样的事。「演示进出」会先播一段，再自己停掉。

## 三个候选

眼睛都是两枚白色胶囊，没有高光。

- 涟漪张望：圆脸和两道细圈是不透明的鲜艳专辑强调色（跟正式样式二同一套换色）。细圈轮流向外淡掉，眼睛慢慢左右看，中途眨一次。正式样式二播的就是这一条。
- 涟漪：半透明白玻璃圆脸，只有两道白细圈。
- 张望：半透明白玻璃圆脸，只有眼睛左右看和眨眼。

没有嘴巴，也不再跟海平面的响度走。

## 离屏

```bash
QT_QPA_PLATFORM=offscreen PYTHONDONTWRITEBYTECODE=1 python3 _demos/broadcast_motion/grab.py
```

每个候选一张横条和一条 webp。
